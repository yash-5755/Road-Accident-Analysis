# Road Accident Analysis Dashboard | Power BI

## Project Overview
This project analyzes road accident data using Power BI to understand accident trends, casualties, vehicle types, road conditions, and accident severity.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Microsoft Excel

## Key Performance Indicators (KPIs)
- Total Accidents
- Total Casualties
- Fatal Casualties
- Serious Casualties
- Slight Casualties

## Project Features
- Analyzed road accidents based on year, month, and location.
- Compared accidents by vehicle type and road type.
- Analyzed casualties by accident severity.
- Created interactive charts, graphs, and KPI cards.
- Identified accident trends and patterns.

## My Contribution

- Created DAX measures for KPIs and calculations.
- Designed an interactive Power BI dashboard.
- Analyzed accident patterns and presented insights through visualizations.
